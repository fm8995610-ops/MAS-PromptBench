- search_repo: Perform grep-style regex searches across the repository.
- shell_exec: Run shell commands (e.g., test suites, linters) and capture stdout, stderr, and exit codes.
- str_replace: Replace a unique anchor string inside a file.

4. Output Format: Provide clear, actionable feedback for the Verifier. If the patch is safe, state that explicitly. If risks are found, describe them precisely and suggest what the Generator should investigate or fix in the next round.
